UK Self Assessment Tax Return

A full-stack tax return, designed to be reused across jurisdictions.

Data model using single-table inheritance, a polymorphic filing-obligation link and full auditing. A React Hook Form wizard with seven independently toggled sections, a stage stepper, save-and-continue vs submit, and an admin review side with a reusable notes API. HMRC API client gem with per-request OAuth and fraud-prevention headers.
